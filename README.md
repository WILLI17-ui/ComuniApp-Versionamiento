# ComuniApp-Versionamiento

Proyecto académico de la asignatura Mantenimiento de Software, orientado al uso de Git, GitHub y técnicas de mantenimiento aplicadas al proyecto ComuniApp.

## Descripción del proyecto

ComuniApp es una propuesta de plataforma web que busca conectar residentes de una comunidad con emprendimientos y servicios locales. El objetivo principal es organizar la oferta de productos y servicios dentro de una comunidad residencial para facilitar su consulta y mejorar la comunicación entre residentes y emprendedores.

## Técnica de mantenimiento aplicada

Para la Actividad 6 se seleccionó la técnica de reingeniería de software. Esta técnica fue aplicada sobre la estructura documental del repositorio, con el fin de mejorar la organización, comprensión y mantenibilidad del proyecto.

## Estructura del repositorio

- `Documentacion`: contiene documentos relacionados con el análisis y diseño del proyecto.
- `mockups`: contiene capturas y prototipos visuales desarrollados en Figma.
- `historias-usuario`: contiene las historias de usuario principales de ComuniApp.
- `evidencias`: contiene capturas del proceso de mantenimiento y versionamiento.
- `.gitignore`: define archivos que no deben ser incluidos en el control de versiones.

## Objetivo de la reingeniería

La reingeniería aplicada busca dejar el repositorio más organizado, claro y fácil de mantener para futuras etapas del proyecto.
